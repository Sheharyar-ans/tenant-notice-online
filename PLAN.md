# TenantNotice.online - Strategic Implementation & Refactor Plan

## Executive Summary
TenantNotice.online is an authoritative, zero-latency, client-side legal document generation engine and statutory guidance portal. This master refactor sprint delivers a dedicated 10-article legal blog hub under `/blog/`, perfects single-page print stylesheet alignment, enforces mobile app-like tactile ergonomics, and hardens enterprise edge manifests across the United States and United Kingdom jurisdictions.

## Active Skills & Architectural Capabilities
- **Mobile-First App Shell & Ergonomics**: Responsive app-like architecture featuring sticky bottom action bars on mobile viewports (< 768px), horizontal scrolling segmented pills for state and ground selection, 48px minimum touch targets, and sticky split-screen desktop workspaces.
- **Client-Side Reactive Compiler**: Zero-data-retention vanilla JavaScript engine. Live input binding renders official legal letterheads in browser memory without server round-trips.
- **Dedicated Single-Page Print Engine**: Completely eliminates all UI chrome, navbars, forms, and footers upon `window.print()`. Millimeter-calibrated typography and margin spacing guarantees authentic legal documents start neatly on Page 1 without empty vertical gaps or phantom padding offsets.
- **Search & Generative Engine Optimization (SEO / GEO / AIO / AEO)**:
  - Exact inverted pyramid heading hierarchies on every tool and blog page.
  - 45-word bold Direct Answer Capsules positioned immediately below single H1 tags.
  - Complete statutory breakdowns: H2 Legal Foundations, H3 Variable Tables, H2 Service of Process, H2 Timelines Matrix, H2 Fatal Mistakes, H2 Conversational FAQs, and H2 Related Utilities.
  - Valid JSON-LD schemas (`WebApplication`, `BlogPosting`, `FAQPage` matching on-page copy 1:1, `BreadcrumbList`, `Organization`, `WebSite`).
- **Comprehensive 10-Article Editorial Blog Hub**: 10 authoritative articles (1,200 to 1,500 words each) covering California notice rules, California AB 1482 just cause, Texas Property Code § 24.005, Florida Statute § 83.56 calculations, multi-state security deposit demands, UK Renters' Rights Act Section 21 abolition, reformed Section 8 Ground 8 arrears, Ground 1A property sale rules, periodic tenant notice to quit, and Section 13 rent challenge tribunal procedures.
- **Security & Crawl Infrastructure**: Cloudflare edge headers (`_headers`), crawler directives (`robots.txt`), XML sitemaps (`sitemap.xml`), and machine-readable context files (`llms.txt`, `llms-full.txt`, `ai-catalog.json`).

## Sprint Roadmap & Milestones
- **Phase 0**: Discovery, audit, and persistent task backlog setup.
- **Phase 1**: Print stylesheet whitespace alignment across all tools.
- **Phase 2**: Mobile app-like UI/UX architecture and 48px touch targets.
- **Phase 3**: Creation of `/blog/index.html` and 10 in-depth statutory articles.
- **Phase 4**: Humanization directives (0 em-dashes, 0 AI tropes, 1,200 - 1,500 words per article).
- **Phase 5**: Conversational FAQs and JSON-LD schema implementation.
- **Phase 6**: Site-wide pillar-cluster internal linking mesh.
- **Phase 7**: Edge cybersecurity, sitemap, llms.txt, and ai-catalog.json updates.
- **Phase 8**: Production verification, Git commit, and deployment to GitHub main branch.
